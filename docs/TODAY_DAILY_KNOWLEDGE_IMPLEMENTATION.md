# 今日首页、日常事务与生活资料

## 用户流程

登录成功后进入 `/today`。今日首页汇总今日任务、日程、未来七天的计划支出和重点 Journey 项目，并提供快速记账、添加任务和写笔记入口。所有模块顶部提供“今日首页”和“全部模块”导航。

日常事务 `/daily` 包含今天、收集箱、即将到期、全部任务、已完成和日程视图。任务区分计划日期与截止时间，支持优先级、父任务和 Journey 项目关联。项目事项可以由用户明确转换为一条日常任务，`source_item_id` 唯一约束避免重复转换。

生活资料 `/knowledge` 支持笔记自动保存、标题与正文搜索、标签、置顶、归档、回收站、恢复、永久删除、Markdown 导出，以及关联 Journey 项目或日常任务。当前 Markdown 以源码方式编辑，不执行 HTML 或脚本。

## 数据与兼容性

迁移 `005_daily_knowledge.sql` 新增：

- `daily_tasks`
- `daily_events`
- `knowledge_notes`
- `today_pinned_projects`

项目删除时任务和笔记解除项目关联；父任务删除时子任务随父任务删除，因此界面会显示影响数量并要求确认。旧数据库按顺序补齐新表，旧版完整备份可以恢复后再执行迁移。新版完整备份会校验任务、日程和生活资料结构。

## 明确限制

- 应用内展示到期状态，尚未提供软件关闭后的系统通知。
- 重复任务、习惯、附件和加密健康/证件资料属于后续功能。
- 普通生活资料未加密；密码和私密日历继续使用各自的安全边界。
- Journey 项目进度仍由原有项目事项和里程碑计算，日常任务不会隐式改变项目进度。

## 2026-09-23 检查与修复

- 笔记写入按记录串行处理，页面离开不会取消已提交的编辑；失败草稿保留在当前应用会话内，可以重试或导出。归档、切换笔记和恢复数据库前等待保存；正常关闭窗口也等待保存，失败时阻止关闭。异常终止进程仍可能丢失尚未落盘内容。
- 修复快速创建在 StrictMode 下重复建笔记、重复选择当前笔记恢复旧正文的问题。
- 项目新建任务默认关联项目，关联任务/笔记和今日项目支持直达记录。
- 日程可以选择任意月份，保存历史或未来记录后自动定位月份；保存期间禁止重复提交。任务保存后进入全部任务视图。
- 任务父子关系由后端拒绝循环关联；编辑子任务不会因视图过滤丢失父任务。
- 今日任务总数不再被 20 条列表上限截断，逾期使用当前时间判断，支持撤销完成；快速记账直接打开录入窗口。
- 新模块备份字段校验补齐，避免缺少字段的备份覆盖当前数据库后导致功能不可用。
