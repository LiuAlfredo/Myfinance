# 0.2.0 发布验收

自动检查：类型、lint、前端测试、Rust 测试、Windows NSIS 构建；产物包含提交号及 SHA256。

人工验收时使用测试数据库，保留已有个人数据库备份：

- 干净安装：首次密码设置、登录、六模块入口、锁定及再次登录。
- 旧版覆盖安装：数据目录一致，按版本升级，账号、交易、项目和私密记录数量一致。
- 编辑笔记后切换/关闭：保存成功；数据库忙时提示失败；重启后可恢复草稿。
- 自动备份：错过的周期补做、目录不可写可重试、只清理本应用生成且校验未变的文件。
- 恢复：预览数量、旧库升级、损坏快照拒绝覆盖、备份时密码重新登录。
- 附件：删除原文件后仍可导出，备份恢复后 SHA256 一致。
- 重复任务：多次启动不重复生成，跳过和删除实例仍保留周期历史。
- 订阅：创建/关联已有支出、重复提交不重复入账、下次日期按日历推进。
- 日程：日周月切换、跨天、闰年、重叠时间、历史/未来日期。

安装包当前不签名；签名密钥、远程自动更新和关机后的系统提醒需要后续部署配置。
