# MyFinance 账号与独立数据库

## 登录和注册

软件启动后输入云账号和至少 12 位密码。没有账号时可直接注册。注册成功后，软件创建账号专属的本地 SQLite 数据库，并生成云备份恢复密钥。

已在本机登录过的账号可以离线解锁本地数据库。离线登录会保留云端连接错误；恢复网络后再次登录即可刷新云会话。新设备首次登录必须连接 Cloudflare。

## 数据隔离

本机目录结构：

```text
应用数据目录/
├── identity.sqlite3
└── profiles/
    └── <accountId>/
        └── myfinance.sqlite3
```

服务端返回的稳定 `accountId` 用于选择目录。用户名不作为目录名。React 无法传入数据库路径；Rust 的当前账号会话决定所有业务命令访问哪个数据库。

退出或切换账号时会清除数据密钥。云备份、恢复等异步账号数据操作完成前，后端会拒绝切换账号，防止操作跨越账号边界。

## 旧数据迁移

检测到旧版公共 `myfinance.sqlite3` 时，登录页显示“原软件密码”。首个绑定账号需要验证原密码。验证通过后使用 SQLite Backup API 创建包含已提交 WAL 页的一致性副本，再把数据密钥改由当前账号密码保护。

旧数据库不会删除。成功迁移后，本机账号索引会记录归属，其他账号创建空数据库，不能再次继承旧数据。

## 云备份恢复密钥

新账号会生成独立恢复密钥，首次注册后必须保存。新设备登录已有云备份的账号时，需要输入原恢复密钥；服务器和账号密码都不能替代它解密历史备份。

快照备份用于灾难恢复，不提供逐条实时同步。
